Seishinkai Karate Federation - Hiragishi Branch (former name)

[Toyohira Ward Misono Branch - Misono Karate Club] (formerly the Hiragishi Karate Club / Seishinkai Hiragishi Branch)
The Hiragishi karate class got its start in April 2009 (Heisei 21), borrowing space at the Toyohira Ward Citizens' Center.
Since March 2021 (Reiwa 3), the venue has moved to the 2nd-floor circle room at Co-op Misono, and the class was renamed the Misono Karate Club (Misono Branch). It is now active as the "Misono Branch," so please see the Misono Branch page for the latest training days and venue information.
Since the venue is a co-op store, it's convenient to be able to shop while training.
Since its founding, the class has centered on Junior Karate, with members ranging from preschoolers to junior high schoolers.
Participation by parents and children together, as well as senior class members, is also welcome.
While many dojos feel like an extension of a school sports club, this one aims to offer karate for health and fitness that members can enjoy learning in a relaxed, club-like atmosphere.
